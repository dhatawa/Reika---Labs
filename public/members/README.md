# Foto Anggota

Taruh foto anggota di folder ini dengan nama file **persis** berikut:

| Anggota | Nama file |
|---|---|
| Dyka Hatawa | `dyka-hatawa.jpg` |
| Reisya Putri Ramadhani | `reisya-putri-ramadhani.jpg` |

- Rasio **4:5 portrait** (contoh 1000 × 1250 px).
- Ukuran file idealnya < 250 KB (kompres di https://squoosh.app).
- Gunakan foto asli. Jangan gunakan wajah buatan AI.

Selama file belum ada, website otomatis menampilkan placeholder berinisial.
Nama file bisa diubah di `src/content/site.ts` → `members.people[].photo`.
